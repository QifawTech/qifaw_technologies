## 🎯 Project Overview

Modern, responsive, production-ready website for an IT products & SaaS company. Features a beautiful public-facing website with animated components and a powerful admin dashboard for content management.

### ✨ Key Features

- 🎨 **Premium UI/UX** — Blue + white theme, dark/light mode, animated robot, glass-morphism navbar
- 🔐 **Secure Admin Panel** — 12 modules with full CRUD, session + CSRF + rate limiting
- 📱 **Mobile Responsive** — Card view for tables, stacked layouts, touch-friendly
- 🚀 **Dynamic Content** — Editable hero, about, mission/vision, settings, logo from admin
- 📊 **Media Library** — Drag-drop image upload, resume downloads, avatar management
- 🔍 **SEO Ready** — Meta tags, sitemap, robots.txt, semantic HTML
- ⚡ **Fast** — Vite + Gunicorn + CDN ready

## 🏗️ Tech Stack

### Frontend
- **React 18** — Modern UI framework
- **Vite** — Fast build tool
- **React Router v6** — Client-side routing
- **Bootstrap 5** — Responsive grid
- **Axios** — HTTP client with interceptors
- **Bootstrap Icons** — SVG icon library

### Backend
- **Python 3.10+** — Core language
- **Flask 3.0** — REST API framework
- **Flask-CORS** — Cross-origin handling
- **Flask-Limiter** — Rate limiting
- **Werkzeug** — Security utilities (password hashing)
- **mysql-connector-python** — MySQL driver (no ORM)

### Database
- **MySQL 8.0** / MariaDB (XAMPP compatible)
- 10 tables with foreign keys, indexes, constraints
- Activity logging, audit trail
